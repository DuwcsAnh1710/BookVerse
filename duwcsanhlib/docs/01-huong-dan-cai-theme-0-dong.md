# Hướng Dẫn Cài Đặt Giao Diện Miễn Phí 0đ Cho DuwcsAnhLib

## 1. Tại sao nên chọn Theme Miễn Phí (Astra / Storefront) thay vì Flatsome khi chưa có License?
- **Ngân sách 0 đồng:** Astra và Storefront hoàn toàn miễn phí trên kho WordPress.org, không lo vấn đề bản quyền, không sợ virus từ các nguồn theme trôi nổi ("nulled").
- **Tương thích hoàn hảo với WooCommerce:** Cả Astra và Storefront đều được thiết kế chuyên biệt cho WooCommerce, tự động tối ưu giao diện Giỏ hàng (Cart), Thanh toán (Checkout), Trang sản phẩm chi tiết (Single Product) và Danh mục (Catalog/Shop).
- **Tốc độ tải trang cực nhanh:** Astra chỉ nặng dưới 50KB, chuẩn SEO, responsive tự động trên điện thoại, máy tính bảng và desktop.

## 2. Các bước cài đặt Theme Astra (Khuyên Dùng)

### Bước 1: Cài đặt và Kích hoạt
1. Truy cập trang quản trị WordPress: `http://<dia-chi-site-local>/wp-admin/`
2. Vào menu **Giao diện (Appearance)** → **Giao diện (Themes)**.
3. Nhấp vào nút **Thêm mới giao diện (Add New Theme)** ở trên cùng.
4. Tại ô tìm kiếm bên phải, gõ từ khóa: `Astra`.
5. Di chuột vào ô **Astra** → Bấm **Cài đặt (Install)** → Chờ vài giây rồi bấm **Kích hoạt (Activate)**.

### Bước 2: Thiết lập Bộ nhận diện thương hiệu DuwcsAnhLib (Design System)
Vào **Giao diện (Appearance)** → **Tùy biến (Customize)**:
1. **Màu sắc tổng thể (Colors):**
   - Theme Color (Màu chủ đạo): `#92400E` (Nâu gỗ trầm ấm / Sang trọng).
   - Link Color (Liên kết): `#B45309`.
   - Text Color (Màu chữ): `#0F172A` (Xanh đen đậm, sắc nét, dễ đọc).
   - Background Color (Nền trang): `#FFFBEB` (Màu kem giấy ngà - phong cách thư viện / sách).
2. **Typography (Kiểu chữ):**
   - Font chữ thân bài (Body): `Inter` hoặc `Roboto` hoặc font mặc định hệ thống.
   - Font tiêu đề (Headings): Chọn font Serif (như `Merriweather` hoặc `Playfair Display`) để tạo nét cổ điển, học thuật của một thư viện tri thức.
3. **Đầu trang (Header Builder):**
   - Tải logo `assets/logo-duwcsanhlib.png` lên mục **Site Identity**.
   - Thêm ô Tìm kiếm sản phẩm (Search) và Biểu tượng Giỏ hàng (Cart) vào Header.
4. **Chân trang (Footer Builder):**
   - Thêm thông tin bản quyền: `© 2026 DuwcsAnhLib. Dự án học tập & thực hành WordPress/WooCommerce.`
